# Shubhankar Mukharjee — Portfolio

A responsive, static portfolio built with HTML, Bootstrap 5.3.8, modern CSS, and vanilla JavaScript. No build step, account, API key, database, or paid service is required.

## Preview

Open `index.html` in a browser, or serve this folder with any static development server. Clipboard copying works best on localhost or HTTPS; if unavailable, the site displays the email address to copy manually.

## Publish

Upload the **contents of this portfolio folder** to your hosting provider's public directory, keeping `index.html` at the root and preserving the `assets` folder. This works with ordinary static hosting. A deployment ZIP is provided alongside this folder.

For repository-based hosting, commit these files at the publishing root and select static-site hosting with no build command. For drag-and-drop hosting, upload this folder. Enable HTTPS and connect your domain using your hosting provider's domain settings. The site uses relative paths and can also run under a repository subdirectory.

After publishing, check the navigation, project dialogs, résumé download, LinkedIn link, and email link from your public URL and a phone. `mailto:` opens the visitor's configured email application; it does not submit a server-side contact form.

## Make it yours

- **Content and links:** edit `index.html`.
- **Project detail text and challenge scenarios:** edit `script.js`.
- **Colors, spacing, typography, and animations:** edit `styles.css`; the active palette is in the Midnight / electric blue / lilac theme at the end of the file.
- **Résumé:** replace `assets/Shubhankar_Mukharjee_Resume.pdf` while retaining that filename, or update both download links.
- **Browser icon:** edit `assets/favicon.svg`.
- **Search and link previews:** title, description, Open Graph text, and Person structured data are in `index.html`. Once you have a domain, add a canonical URL and `og:url`. Add a hosted social preview image if desired.

Before launch, review current employment dates and project descriptions. The downloadable résumé contains your supplied contact details and client references. The website uses your email and LinkedIn; it does not separately display your phone number. Confirm that you want the attached résumé and named engagements publicly available.

## Included features

- Responsive layout, sticky navigation, and mobile menu.
- CSS-animated systems illustration, scroll reveals, and hover transitions.
- Professional experience, skills, education, and four selected work summaries.
- Personal interests: cars, driving and riding, travel and exploration, and former competitive gaming.
- Professional portrait, four personal travel photos, and a personal background note on Bengali mother tongue and Odia-medium schooling.
- Photos are optimized as local WebP files in `assets/photos/`; gallery photos open in full in a new tab.
- Project filters and keyboard-accessible native dialog details.
- Optional API challenge with three scenarios, explanations, scoring, and replay.
- Copy email, LinkedIn link, and downloadable résumé.
- Skip link, visible focus, semantic sections, reduced-motion support, and no timer in the game.
- Content remains readable without JavaScript; interactive filters, dialogs, and the game require JavaScript.
- Bootstrap CSS/JavaScript bundled locally. No remote fonts, analytics, trackers, or form services.
